# 게더타운 스토리형 게임
## 🎮게임소개
학교폭력을 당하고 있는 플레이어가 똑같이 학교폭력을 당하고 있는 친구(연우)의 일기장을 보게된다.</br>
게임은 플레이어가 자신의 모습을 연우에게 투영하고, 연우를 구하기 위한 여정에 나서면서 시작된다.</br>
여러 스테이지를 거치며 연우가 그동안 받던 피해 정황들을 확인하게 되며, 플레이어는 연우의 고통을 이해하게 된다.

## 📖게임 방법
**게더타운 게임 링크:** https://app.gather.town/app/WwkcA553MSYl0d1s/classroom%201 </br>
**step1.** 각 스테이지 별 연우의 일기장 내용이 담긴 오브젝트를 찾는다.</br>
**step2.** 오브젝트를 선택하여 일기장의 내용을 확인 후 다음 스테이지로 간다.</br>
**step3.** 각 스테이지 별로 해당 과정을 반복하며 연우를 찾는다.
</br>
</br>

## 📌공지사항
- 현재 게더타운과 Twine 연동에 오류가 발생함에 따라 오브젝트 선택 시 확인 가능한 연우의 일기장 내용을 확인하기 어려움</br>
**해결) 각 스테이지 별로 먼저 특정 오브젝트를 찾은 후, 각 스테이지 이름이 적힌 첨부된 html 파일 따로 실행**</br>

  - 이에 따라, 특정 효과가 발생하는 오브젝트를 찾는 것에 어려움</br>
  **해결) 특정 오브젝트에 다가가거나 혹은 x키를 누를 때, 장면 전환이 발생하게 되는 오브젝트 찾기**
